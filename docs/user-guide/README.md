# HR Pulse user guide

This guide explains the current HR Pulse beta from each user’s point of view. Choose the page that matches your role. Your available screens depend on your active membership in the selected organization.

## Choose your guide

| Role | Start here | Main work |
| --- | --- | --- |
| Employee | [Employee guide](employee.md) | Record attendance, prepare timecards, request time off, and use self service |
| Manager | [Manager guide](manager.md) | Review direct reports, attendance, timecards, and time off requests |
| Administrator | [Administrator guide](administrator.md) | Configure the organization, manage payroll and access, and oversee operations |

The same person can have different roles in different organizations. Use **Switch organization** when you need to change workspaces.

## How access works

1. Sign in with your provisioned work email and password.
2. If you belong to more than one organization, choose the organization you want to use.
3. If your profile is inactive or has no active membership, HR Pulse sends you to **Pending access**.
4. If a feature is not visible, it may be disabled for this environment or your role may not include it.

HR Pulse checks access again on the server for every protected action. Seeing a link is never the only permission check.

## Current beta limits

Payroll and attendance show a synthetic beta notice. Use test or synthetic employee data only. The product does not send external payroll transfers or calculate regional taxes. Timecards, time off, self service, privacy controls, and operations are controlled separately and may not be available in every environment.

If a feature is unavailable, ask an administrator whether its release setting is enabled. Refreshing the page does not enable a disabled feature.

## Shared navigation

The workspace navigation may include:

* Dashboard
* Payroll
* Operations
* Attendance
* Timecards
* Time off
* My self service
* Privacy
* Privacy operations
* Switch organization

On a small screen, open the navigation menu from the top bar. Use **Sign out** when you finish on a shared device.
